# Reviewer Response

Use this skill for journal or conference revisions.

- Preserve each reviewer comment verbatim and assign it a stable identifier.
- Classify the request as clarification, analysis, experiment, evidence, writing, formatting, or disagreement.
- For every comment, record the decision, rationale, required evidence, manuscript location, exact change, and response text.
- Do not claim that an experiment, analysis, or edit was completed until it has been performed and verified.
- Disagree respectfully when a request is unsupported or infeasible, and explain the evidence and manuscript clarification used instead.
- Keep the response letter synchronized with the revised manuscript.
